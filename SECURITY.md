# Security Policy

This repository holds Kubernetes manifests and bootstrap scripts that ArgoCD
syncs from `main` into a cluster. Treat it as a deployment source.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/k3s-argocd-sandbox/security/advisories/new>

Never include real passwords, kubeconfigs, tokens or cluster addresses in
issues or pull requests; use redacted values.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` receives security fixes.
